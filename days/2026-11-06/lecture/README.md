## 실행 방법
1. **설치** : `pip install keras torch` (Colab 은 둘 다 기본 포함)
   - `keras` 는 IMDB 데이터 받기와 `pad_sequences` 에만 쓴다 — **TensorFlow 가 없어도** PyTorch 를 백엔드로 동작 (노트가 `KERAS_BACKEND=torch` 를 설정)
2. **데이터** : 첫 실행 때 IMDB(17MB) · 단어 사전(1.6MB)을 자동으로 받는다 — 따로 준비할 파일 없음
3. **실행** : 노트북을 열고 맨 위부터 **[런타임] → [모두 실행]**. 각 노트북 0절에 설치 셀(주석 처리)이 있다
4. **시간** : `matmul_rnn_cell` 은 몇 초, `imdb_rnn_sentiment` 는 CPU 로 약 5분(에폭당 약 10초 · 15 에폭 + post 실험 5 에폭). GPU 는 필수 아님
