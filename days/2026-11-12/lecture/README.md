## 출력을 읽는 법 (중요)

정리 노트북은 **API 키가 없는 환경**에서 만들었다. OpenAI 서버를 부르는 셀은 첫 줄의 표시로 구분한다.

| 표시 | 뜻 |
|---|---|
| `# 📼` | **수업 시간에 실제로 실행한 결과**를 필기 · 강의 노트북에서 그대로 옮긴 출력 |
| `# ⏳` | 수업 때 결과가 남지 않아 **출력이 비어 있는 셀** — 직접 실행 (총 9개 : API 기초 3 · 프롬프트 2 · 감성 분석 4) |
| 표시 없음 | 정리 노트북에서 실제로 실행한 셀 (토큰 세기 · JSON 변환 · 오류 재현 · 사용량 · 요금 계산 · 형식 확인) |

`review_sentiment_analysis.ipynb` 는 필기가 오류에서 멈춰 **모델 응답이 하나도 없다.** API 셀 4개를 직접 돌려야 결과가 채워진다.

## 실행 방법
1. **설치** : `pip install openai python-dotenv tiktoken pandas`
2. **API 키** : 노트북 폴더(또는 상위 폴더)에 `.env` 파일 → `OPENAI_API_KEY="sk-…"`. **`.env` 는 올리지 않는다**(저장소 `.gitignore` 에 포함)
3. **실행** : 노트북을 열고 맨 위부터 **모두 실행**. 인터넷 필요, 호출마다 몇 초~수십 초
4. **요금** : 모델 `gpt-5-nano` (입력 $0.05 · 출력 $0.40 / 100만 토큰, 2026-11 기준). 일반 호출 1번 약 $0.0006, 웹 검색 1번 약 $0.004 + 검색 도구 요금 — 세 노트북을 모두 돌려도 몇 센트 수준
