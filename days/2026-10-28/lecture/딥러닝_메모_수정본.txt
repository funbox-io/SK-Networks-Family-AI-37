1. 경사하강법 (경사하강법.pdf)
────────────────────────────────────────
회귀 문제: 출력층 출력 뉴런 -> 입력 [수정: 신호]의 총합 Wx -> 예측값 y
  (원본 "입력 함수의 총합" -> "입력 신호의 총합")

손실 함수(MSE, 데이터 1개면 제곱 오차) L = (1 - y)^2 , y = wx , x = 1 -> L = (1 - w)^2 -> 포물선

  w = 3 (출발)  -> 손실 L = 4
  w = 2         -> 손실 L = 1
  w = 1         -> 손실 L = 0  (학습 목표)

기울기 dL/dw = -2(1 - w)
  w = 3 -> +4 , w = 2 -> +2 , w = 1 -> 0
  기울기가 + 이면 w 를 줄이고, - 이면 w 를 키운다 (기울기의 반대 방향)

경사하강법: w_new = w_old - 학습률 × 기울기
  학습률 0.1 이면 w: 3 -> 2.6 -> 2.28 -> 2.024 -> ... -> 1.023 (20 걸음)

결론: 가중치 W 변화 -> 손실이 커질수록 접선의 기울기도 커지고, 작아질수록 기울기도 작아진다.
  [수정] 이 말은 볼록한 포물선(제곱 오차)에서만 성립한다. |기울기| = 2|1 - w| = 2·√L.
         언덕이 있는 손실 곡선은 손실이 큰데 기울기가 0 인 곳(언덕 꼭대기)도 있다.

경사가 하강하는 방향으로 가중치 이동 = 경사하강법

2. 다중 분류 손실 (다중_분류_손실.pdf)
────────────────────────────────────────
문제: 개 · 고양이 · 호랑이 맞추기, 입력 = 고양이 사진 -> 정답 레이블 [0 1 0] (원-핫 인코딩)

출력층 뉴런 3개
  y1 = W11*x1 + W12*x2 + b1 = n1   -> (소프트맥스) -> 0.1  '개' 일 확률
  y2 = W21*x1 + W22*x2 + b2 = n2   -> (소프트맥스) -> 0.7  '고양이' 일 확률
  y3 = W31*x1 + W32*x2 + b3 = n3   -> (소프트맥스) -> 0.2  '호랑이' 일 확률
  [수정] n1, n2, n3 는 점수(입력 신호의 총합, logit) 이고, 0.1 / 0.7 / 0.2 는 소프트맥스를 거친 뒤의 확률.

교차 엔트로피 E = - Σ t_k · log(y_k)   (log = 자연로그)

1) 첫 번째 출력 뉴런 (예측 0.1), t = 0 -> 0 × log(0.1) = 0 -> 손실에 참여 X
2) [수정: 번호 1) -> 2)] 두 번째 출력 뉴런 (예측 0.7), t = 1 -> 1 × log(0.7) = log(0.7)
결론: 다중 분류의 손실은 정답(레이블 1)에 해당하는 출력 뉴런의 예측 확률 하나로만 계산한다.
  E = -(0 × log 0.1 + 1 × log 0.7 + 0 × log 0.2) = -log 0.7 ≈ 0.357

[예시] 고양이 · 강아지 · 사람 · 자동차 · 집 5가지 분류, 입력 = 사람 -> t = [0 0 1 0 0]
  소프트맥스 출력 p1 ~ p5 , p3 = 0.7
  Σ t·log(P) = 0·log p1 + 0·log p2 + 1·log p3 + 0·log p4 + 0·log p5 = log(0.7) ≈ -0.357 (음수)
  E = -Σ t·log(P) = -log(0.7) ≈ 0.357 (양수)
  [수정] 원본은 "t·log(P) = 1·log(p3) = -log(0.7) (양수)" 로 마이너스가 중간에 끼어 있었다.
         Σ t·log P 자체는 음수이고, 앞에 - 를 붙인 E 가 양수.
  -> 학습 목표: p3 를 1 에 가깝게 해서 E 를 0 으로

log 함수 특징: 입력이 1 보다 작으면 출력이 음수, log 1 = 0
  -> 확률(0~1)의 log 는 항상 0 이하라서 앞에 - 를 붙여 손실을 양수로 만든다.
