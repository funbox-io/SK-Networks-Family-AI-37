## 📚 수업

**주제**  
파이썬 기초 문법 — 출력, f-string, 자료형, 연산자, 리스트

**핵심 키워드**  
`print` `f-string` `int/float/str/bool` `산술·비교·논리 연산자` `진법 변환` `리스트` `인덱싱` `슬라이싱` `중첩 리스트`

**배운 내용**
- `print()` — 인자를 여러 개 넘기면 공백으로 이어 붙는다. `sep` 으로 구분자를, `end` 로 줄 끝 문자를 바꾼다.
- f-string — 문자열 앞에 `f` 를 붙이면 `{}` 안의 **표현식이 값으로 치환**된다. 서식은 `{pi:.2f}`, `{n:,}`, `{0.85:.1%}` 처럼 쓰고, `{var = }` 는 변수명과 값을 함께 찍는 디버깅용이다.
- 자료형 — 파이썬은 동적 타이핑이라 대입한 값으로 타입이 정해진다. `int` `float` `str` `bool` 네 가지가 기본이고, **char 타입은 없어서 `'A'` 도 길이 1인 문자열**이다. `bool` 은 `int` 의 하위 타입이라 `True + True == 2`.
- 형 변환 — `int("123")`, `float("3.14")`, `str(100)`. `int(3.9)` 는 반올림이 아니라 **소수점 버림**이고, `0` · `""` · `[]` 는 모두 `False`.
- 산술 연산자 — `+ - * / // % **`. `/` 는 나누어떨어져도 항상 `float` (`4 / 2 → 2.0`), 제곱근은 `9 ** 0.5`.
- 비교·논리 연산자 — 결과는 항상 `bool`. `80 <= score < 90` 처럼 이어 쓸 수 있다. `and` 는 둘 다 참, `or` 는 **하나라도 참**, `not` 은 뒤집기.
- 진법 변환 — `bin()` `oct()` `hex()` 는 접두사가 붙은 **문자열**을 반환한다. 접두사 없이 보려면 `f"{n:b}"`, 되돌릴 땐 `int("ff", 16)`.
- 리스트 — `[ ]` 로 값 여러 개를 묶는다. 순서가 있고, 값을 바꿀 수 있고(mutable), 자료형을 섞어도 된다. `+` 는 연결, `*` 는 반복, 길이는 `len()`.
- 인덱싱 — 번호는 **0부터** 시작하고 `-1` 이 마지막. 범위를 넘기면 `IndexError`.
- 슬라이싱 — `[시작:끝:간격]` 이고 **끝 인덱스는 포함되지 않는다**. `[::-1]` 로 뒤집기, 문자열에도 똑같이 쓸 수 있다.
- 중첩 리스트 — 리스트 안의 리스트는 `list_data5[3][0]` 처럼 대괄호를 두 번 써서 바깥→안쪽 순으로 꺼낸다.
- 리스트 메서드 — `append` `insert` `remove` `pop` `sort` `reverse`. 대부분 **원본을 바꾸고 `None` 을 반환**하므로 `lst = lst.sort()` 로 쓰면 리스트가 사라진다.
