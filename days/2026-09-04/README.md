## 1. 모니터 출력 (`print`)

`print()` 는 값을 화면에 출력하는 내장 함수다. 인자를 여러 개 넘기면 기본적으로 **공백**으로 구분해 이어 붙인다.

- `sep` : 값 사이 구분자 (기본값 `' '`)
- `end` : 출력 끝에 붙는 문자 (기본값 `'\n'` = 줄바꿈)

```python
var = 100

print("var =", var)              # 인자 여러 개 -> 공백으로 이어 붙음
print(2026, 9, 5, sep="-")       # 2026-9-5

print("줄바꿈", end=" 없이 ")     # 줄바꿈 대신 다른 문자로 끝내기
print("이어서 출력")              # -> 두 print가 한 줄에 이어진다
```

## 2. f-문자열 (f-string)

문자열 앞에 `f` 를 붙이면 중괄호 `{}` 안의 **표현식이 값으로 치환**된다.

```python
fsval = "Fstring"

print(f"(X) f접두사:{fsval}, type(fsval)")     # type(fsval)이 중괄호 밖 -> 글자 그대로 출력
print(f"(O) f접두사:{fsval}, {type(fsval)}")   # 중괄호 안에 넣어야 실행된다
print(f"var * 2 = {var * 2}")                 # 중괄호 안에서는 계산식도 가능
```

**자주 쓰는 서식(format spec)**

```python
pi = 3.141592653589793

print(f"소수점 2자리 : {pi:.2f}")               # 3.14
print(f"전체 10칸 오른쪽 정렬 : |{pi:>10.3f}|")
print(f"천 단위 콤마 : {1234567:,}")            # 1,234,567
print(f"백분율 : {0.8567:.1%}")                 # 85.7%
print(f"{var = }")                             # 변수명과 값을 함께 (디버깅용, 3.8+)
```

## 3. 자료형 (Data Type)

파이썬은 변수를 선언할 때 자료형을 적지 않는다(동적 타이핑). **대입된 값에 따라 자료형이 자동으로 정해진다.**

| 값 예시 | 자료형 | 이름 |
|---|---|---|
| `100` | `int` | 정수 |
| `1.0` | `float` | 실수 |
| `"A"`, `"OUTPUT"` | `str` | 문자열 |
| `True`, `False` | `bool` | 논리값 |

> ⚠️ C/Java와 달리 파이썬에는 **문자(char) 타입이 없다.** `'A'` 도 길이가 1인 문자열(`str`)이다.
> 그리고 `bool` 은 사실 `int` 의 하위 타입이라 `True == 1`, `False == 0` 이다.

**형 변환 (casting)**

```python
print(int("123") + 1)      # 문자열 -> 정수
print(float("3.14") * 2)   # 문자열 -> 실수
print(str(100) + "점")      # 정수 -> 문자열 (문자열끼리만 + 가능)
print(int(3.9))            # 3  <- 반올림이 아니라 소수점 버림
print(bool(0), bool(""), bool([]))   # 0, 빈 문자열, 빈 리스트는 모두 False
print(True + True)         # 2  <- bool 은 int 의 하위 타입
```

## 4. 연산자

### 산술 연산자

| 기호 | 의미 | 예 | 결과 |
|---|---|---|---|
| `+` | 더하기 | `7 + 2` | `9` |
| `-` | 빼기 | `7 - 2` | `5` |
| `*` | 곱하기 | `7 * 2` | `14` |
| `/` | 나누기 | `7 / 2` | `3.5` |
| `//` | 몫 (소수점 버림) | `7 // 2` | `3` |
| `%` | 나머지 | `7 % 2` | `1` |
| `**` | 거듭제곱 | `2 ** 10` | `1024` |

- `/` 는 나누어떨어져도 항상 실수(`float`)를 돌려준다. `4 / 2` → `2.0`
- 제곱근은 지수를 `1/2` 로 주면 된다. `9 ** 0.5` → `3.0`
- `1e3` 은 지수 표기로 `1000.0` 이며 정수가 아니라 **실수**다.

### 비교 연산자

| 기호 | 의미 |
|---|---|
| `==` | 같다 |
| `!=` | 같지 않다 |
| `<` `>` | 작다 / 크다 |
| `<=` `>=` | 작거나 같다 / 크거나 같다 |

- 결과는 항상 `True` 또는 `False` 다.
- `=` 는 값을 넣는 **대입** 연산자다. "같다"는 `==`.
- 수학처럼 이어서 쓸 수 있다.

```python
score = 85
print(80 <= score < 90)   # (80 <= score) and (score < 90) 와 같은 뜻
```

### 논리 연산자

| 기호 | 참(`True`)이 되는 조건 | 예 |
|---|---|---|
| `and` | A와 B가 **모두** 참일 때 | `True and False` → `False` |
| `or` | A와 B 중 **하나라도** 참일 때 | `True or False` → `True` |
| `not` | 뒤의 값이 거짓일 때 (참↔거짓 뒤집기) | `not True` → `False` |

숫자 `0`, 빈 문자열 `""`, 빈 리스트 `[]` 는 거짓으로 취급된다.

### 진법 변환

| 함수 | `n = 255` 일 때 결과 | 반환 자료형 |
|---|---|---|
| `bin(n)` | `'0b11111111'` | `str` |
| `oct(n)` | `'0o377'` | `str` |
| `hex(n)` | `'0xff'` | `str` |

세 함수 모두 정수가 아니라 접두사가 붙은 **문자열**을 돌려준다.

```python
n = 255

print(f"2진수: {n:b}, 8진수: {n:o}, 16진수: {n:X}")   # 접두사 없이 보기
print(int("11111111", 2), int("ff", 16))            # 문자열 -> 정수 (두 번째 인자가 진법)
```

## 5. 리스트 · 인덱싱 · 슬라이싱 · 중첩

변수 하나에는 값을 하나만 담을 수 있다. 값이 여러 개일 때 변수를 100개 만들 수는 없으니, **대괄호 `[ ]`** 안에 값을 쉼표로 나열해 하나로 묶은 것이 리스트다.

- **순서가 있다.** 넣은 순서가 유지되고, 순서 번호(인덱스)로 값을 꺼낸다.
- **값을 바꿀 수 있다(mutable).** `lst[0] = 99`
- **자료형을 섞어도 된다.** 숫자와 문자열, 심지어 리스트까지 함께 담을 수 있다.
- `+` 는 두 리스트를 이어 붙이고, `*` 는 반복한다. 길이는 `len()` 으로 센다.

```python
list_data1 = [1, 2, 3]                  # 정수 리스트
list_data2 = ['1', '2', '3']            # 문자열 리스트 ('1'과 1은 다른 값!)
list_data3 = ["ABC", "String"]
list_data4 = list_data1 + list_data3    # + 는 이어 붙이기
list_data5 = [1, 2, 3, ['a', 'b', 'c']] # 중첩 리스트

print("길이 :", len(list_data4))
print("반복 :", list_data1 * 2)
```

### 인덱싱 — 값 하나 꺼내기

각 자리에 **0부터 시작하는 번호(인덱스)** 가 붙어 있다. 1이 아니라 0부터다. 음수를 쓰면 뒤에서부터 세며 `-1` 이 마지막이다. 범위를 넘기면 `IndexError`.

### 슬라이싱 — 여러 값을 잘라내기

`리스트[시작:끝:간격]` 형태로 구간을 잘라 **새 리스트**로 얻는다.

- **끝 인덱스는 포함되지 않는다.** `nums[1:3]` 은 1번과 2번만.
- 시작을 생략하면 처음부터, 끝을 생략하면 마지막까지.
- 간격에 `-1` 을 주면 거꾸로 뒤집힌다.

```python
nums = [10, 20, 30, 40, 50]
#        0   1   2   3   4     <- 인덱스
#       -5  -4  -3  -2  -1     <- 음수 인덱스

print(nums[0], nums[-1])   # 10 50
print(nums[1:3])           # [20, 30]   <- 끝 인덱스 3은 제외
print(nums[:3], nums[-2:]) # [10,20,30] [40,50]
print(nums[::2])           # [10, 30, 50]
print(nums[::-1])          # [50, 40, 30, 20, 10]
```

슬라이싱은 문자열에도 똑같이 쓸 수 있다. `"파이썬"[0:2]` → `'파이'`

### 중첩 리스트 — 리스트 안의 리스트

표(행과 열)나 좌표처럼 묶음이 여러 개인 자료를 다룰 때 쓴다. `list_data5[3]` 은 값 하나가 아니라 **리스트 전체**이고, 안쪽 값을 꺼내려면 대괄호를 한 번 더 붙인다.

```python
list_data5 = [1, 2, 3, ['a', 'b', 'c']]

print(list_data5[3])        # ['a', 'b', 'c']
print(list_data5[3][0])     # 'a'   <- 바깥 -> 안쪽 순서

# print("값:" + list_data5[0])   # TypeError! 문자열 + 숫자는 안 된다
print("값:" + str(list_data5[0]))
```

### 자주 쓰는 리스트 메서드

| 메서드 | 하는 일 |
|---|---|
| `append(값)` | 맨 뒤에 값 추가 |
| `insert(위치, 값)` | 지정한 위치에 값 삽입 |
| `remove(값)` | 그 값을 앞에서부터 찾아 하나 삭제 |
| `pop()` | 맨 뒤 값을 꺼내면서 삭제 (꺼낸 값을 반환) |
| `sort()` | 오름차순 정렬 (`reverse=True` 면 내림차순) |
| `reverse()` | 순서 뒤집기 |

> ⚠️ 이 메서드들은 대부분 **원본 리스트를 직접 바꾸고 `None` 을 반환**한다.
> `lst = lst.sort()` 처럼 대입하면 리스트가 사라진다. 그냥 `lst.sort()` 로 호출할 것.

메서드는 아니지만 함께 자주 쓰는 것들: `len()` `max()` `min()` `sum()`, 그리고 값이 있는지 확인하는 `in`.
