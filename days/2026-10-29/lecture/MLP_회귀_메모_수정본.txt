1. MLP 회귀 모델 구조 (p.1)
────────────────────────────────────────
X_train: 13개의 컬럼 -> 입력 신호 13개
  [수정] 원본은 "10개" — 10개는 어제 타이타닉 데이터. 보스턴 주택은 특성 13개 (medv 는 정답이라 제외)

입력층 (x1 ~ x13)  ->  은닉층 뉴런 n개  ->  출력층 (뉴런 1개)

은닉층 j 번째 뉴런:
  y_j = W_j1*x1 + W_j2*x2 + ... + W_j13*x13 + b_j   ->  ReLU(y_j) = h_j
  [수정] 원본은 뉴런 1번과 n번이 모두 같은 W1 ... W10 으로 적혀 있음.
         뉴런마다 자기만의 가중치 13개 + 편향 1개를 가진다 (그래서 nn.Linear(13, 64) 의 W 모양이 (64, 13)).
  화살표(x1 -> 1번 뉴런, x1 -> n번 뉴런 ...) 하나하나가 서로 다른 가중치 하나.

출력 뉴런:
  y = V1*h1 + V2*h2 + ... + Vn*hn + c = output
  [수정] 출력 뉴런의 입력은 x 가 아니라 은닉층 출력 h1 ~ hn (ReLU 를 거친 값).
         가중치도 은닉층과 다른 것이라 V, c 로 구분.
  출력 뉴런에는 활성화 함수가 없다 (항등 함수) -> output 이 그대로 예측 집값.
  -> 집값은 어떤 실수든 나올 수 있어야 하므로 출력층 뒤에 ReLU / 시그모이드를 붙이지 않는다.

필기 코드에서는 은닉층이 2개: 13 -> 64 -> ReLU -> 32 -> ReLU -> 1  (학습 파라미터 3,009개)

2. 손실 함수 · 옵티마이저 (p.2)
────────────────────────────────────────
① 회귀 손실 함수: criterion = nn.MSELoss()  (평균 제곱 오차)
   - 예측값과 실제값의 차이를 제곱하여 평균을 낸 지표
   - MSE = (1/n) Σ (예측 - 정답)^2   , 단위는 (천 달러)^2
   - 평가에는 RMSE = √MSE 를 쓰면 정답과 같은 단위(천 달러)라 읽기 쉽다
   - 정답 텐서는 (N, 1) 로 맞춘다: batch_y.unsqueeze(1)
     (안 맞추면 (16,1) 과 (16,) 이 브로드캐스팅되어 MSE 가 2.2 -> 135.8 로 틀리게 계산, 에러 없이 경고만)

② 옵티마이저: optimizer = optim.Adam(model.parameters(), lr=0.01)
   - 손실을 최소화하는 방향으로 모델 내 모든 가중치 · 편향(model.parameters())을 자동 갱신
   [수정] 필기 코드는 lr=0.005. 같은 시드로 비교하면
          lr 0.01  -> 42 에포크에 평가 RMSE 최저 3.98, 200 에포크엔 4.78 (빨리 과대적합)
          lr 0.005 -> 200 에포크 평가 RMSE 3.87 (가장 좋음)
          lr 0.001 -> 3.95 (느리지만 안정적)
