순열 중요도 (Permutation Importance) - 평가용 데이터로 평가
평가용 데이터에 대한 best 모델의 성능을 먼저 측정한다. (예: F1 점수)
컬럼 하나씩 값을 무작위로 섞어가면서 best 모델 성능을 다시 측정하고, 성능이 얼마나 감소했는지 측정한다.
-> 성능이 많이 떨어질수록 중요한 특성이다.
==========================================
학습 데이터와 평가 데이터는 반드시 분리해야 한다.
(같은 데이터로 평가하면 과대적합을 발견할 수 없다.)
단, 두 데이터의 컬럼 구성과 전처리 방식은 같아야 한다.
순열 중요도를 학습 데이터로 계산하면 모델이 외운(과대적합된) 특성이 중요하게 나올 수 있으므로 평가 데이터로 계산한다.
매개변수: n_repeats (컬럼마다 섞는 반복 횟수. 컬럼이 많을수록, 반복이 많을수록 실행 속도가 느리다.)
==========================================
특성 중요도
permutation_importance() 결과는 Bunch 객체이며, 키(값)를 가져오는 방법은 2가지다.
  - 딕셔너리 방식: result['importances_mean']
  - 번치(속성) 방식: result.importances_mean

로지스틱 회귀 고도화: 계수(coef_, 기울기)의 크기로도 특성 중요도를 확인할 수 있다.

==========================================
퍼셉트론

인공 뉴런: 여러 개의 입력 신호를 받아 하나의 신호를 출력한다.
가중치(w): 각 입력 신호가 얼마나 중요한지를 나타내는 값
가중합: 각 입력에 가중치를 곱한 뒤 모두 더한 값(+ 편향)
        이 값이 임계값 이상이면 1, 미만이면 0을 출력한다.
가중합 식(w1x1 + w2x2 + b)은 다중 선형 회귀식과 같은 형태이며,
여기에 계단 함수를 적용하면 결정 경계로 분류하는 선형 이진 분류기로 사용할 수 있다.
==========================================
수학적 정의
여러 입력 값 x(x1, x2)를 받아 y를 출력 (편향 b = -임계값)
y = 0 : w1x1 + w2x2 + b < 0  (반응하지 않는다)
y = 1 : w1x1 + w2x2 + b >= 0 (반응한다)

퍼셉트론 = 이진 분류기
결정 경계(직선)를 기준으로 분류
==========================================
퍼셉트론의 의의와 필요성
신경망 그림에서 동그라미(노드) 하나가 "퍼셉트론"(인공 뉴런)이다.
퍼셉트론을 여러 층 쌓은 것이 MLP(다층 퍼셉트론), 은닉층이 많은 깊은 신경망이 DNN이다.
==========================================
논리 게이트
개념: 입력이 특정 조건을 만족할 때만 1(신호)을 출력한다.
편향(b) 비교:
  AND: 두 입력이 모두 1이어야 하므로 편향이 더 큰 음수 (예: -0.7)
  OR : 하나만 1이어도 되므로 편향이 0에 가까운 음수 (예: -0.2)

AND : 둘 다 1일 때만 1
OR  : 하나라도 1이면 1
NAND: NOT AND. 둘 다 1일 때만 0, 나머지는 1
      (AND의 가중치와 편향 부호를 모두 반대로: w = -0.5, b = 0.7)
XOR : 배타적 논리합. 두 입력 값이 서로 다를 때만 1(True)
==========================================
단층 퍼셉트론의 한계와 다층 퍼셉트론 (MLP)
단층 퍼셉트론은 직선 하나(w1x1 + w2x2 + b = 0)로만 영역을 나눌 수 있어 XOR을 구현할 수 없다.
-> 층을 쌓은 다층 퍼셉트론(MLP)으로 해결한다.

딥러닝: 가중치와 편향을 사람이 정하지 않고, 학습을 통해 자동으로 바뀐다(갱신된다).

퍼셉트론을 이용한 AND/OR 게이트 구현
가중치(W): w1 = 0.5, w2 = 0.5
입력(X)  : x1 = 1,   x2 = 1   (논리 게이트 입력은 0 또는 1)

AND (b = -0.7): 0.5*1 + 0.5*1 - 0.7 = 0.3 >= 0 -> 1
OR  (b = -0.2): 0.5*1 + 0.5*1 - 0.2 = 0.8 >= 0 -> 1
(입력 (1, 0)일 때: AND = 0.5 - 0.7 = -0.2 -> 0 / OR = 0.5 - 0.2 = 0.3 -> 1)

XOR 구현
1단계: NAND와 OR 게이트를 병렬로 배치: 입력층의 데이터 (x1, x2)가 두 게이트에 동시에 들어간다.
2단계: 은닉층 노드 1(s1): 두 입력에 대해 NAND 연산을 수행 (둘 다 1일 때만 0, 나머지는 1)
3단계: 은닉층 노드 2(s2): 두 입력에 대해 OR 연산을 수행 (하나라도 1이면 1)
4단계: 출력층 노드(y): 은닉층의 결과물(s1, s2)을 입력받아 AND 연산 수행 -> XOR 문제 해결
==========================================
게이트의 유기적 조합: input(x1, x2 동시 입력) -> {NAND -> s1, OR -> s2} -> AND(s1, s2) -> OUTPUT(y)
==========================================
분류
출력층의 활성화 함수
계단 함수(0과 1만 출력): 퍼셉트론의 "활성화 함수" (최적화 함수 optimizer와는 다르다)
"계단 함수"를 매끄럽게 발전시킨 것이 시그모이드 함수 (0~1 사이 연속값 출력, 이진 분류에 사용)
다중 클래스 분류: 소프트맥스 함수

출력층(소프트맥스): 은닉층에서 넘어온 값으로 레이블(클래스) 수만큼의 인공 뉴런이 각각 가중합 z를 계산하고,
                   소프트맥스가 이를 각 클래스의 확률로 바꾼다.
소프트맥스 식: yk = e^(zk) / Σ e^(zi)
  분자: 해당 클래스의 e^(zk) / 분모: 모든 클래스의 e^(zi)의 합
  -> 모든 클래스의 출력(확률)을 더하면 1 (= 100%)

e**x (= e^x, 지수함수)
출력층 각 뉴런의 입력 신호 총합 z를 지수 자리(x)에 대입한다.
==========================================
z = 입력 신호 총합 (인공 뉴런의 가중합: w1x1 + w2x2 + b)
b는 편향이며 X축이 아니다.
예시 입력: z = 5 (그래프에서 X축에 놓이는 값)
e ≈ 2.718 (자연상수)
==========================================
회귀
출력층의 인공 뉴런 -> 입력 신호의 총합 계산 -> 활성화 함수(항등 함수 y = x) -> 입력 신호의 총합을 그대로 출력

은닉층: ReLU 함수 (Rectified Linear Unit), 가중합 z를 입력으로 받는다.
0보다 크면 입력받은 값을 그대로 출력! (하지만 0 이하(음수)는 0으로 한다.)
ReLU(x) = max(0, x): 0과 x 중 큰 수를 선택한다. -> 음수는 0이 된다.
==========================================
np.exp(x): 제곱이 아니라 지수함수 e^x (제곱은 x**2 또는 np.square())
이진 분류에서 시그모이드 출력 p = 0.7 이면
  클래스 1일 확률 = p = 0.7
  클래스 0일 확률 = 1 - p = 0.3 (1에서 p 값을 뺀다)
==========================================
출력층의 뉴런 수 정하기
분류: 범주(클래스)를 구분한다.
회귀: 연속적인 수치를 예측한다.

이진 분류: 출력 뉴런 1개 (시그모이드)
다중 분류: 출력 뉴런 = 클래스 수 (소프트맥스)
회귀 (예: 주택 가격 예측): 출력 뉴런 1개 (항등 함수)
