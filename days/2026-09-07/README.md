---

## 📚 수업

**주제**  
파이썬 기초 자료형 — 리스트 · 딕셔너리 · 튜플 · 숫자형 · 문자열 · 불(bool)

**핵심 키워드**  
`중첩 리스트` `인덱싱` `슬라이싱` `mutable/immutable` `dict` `key-value` `get()` `tuple` `int/float` `//` `%` `**` `여러 줄 문자열` `문자열 연산` `bool` `f-string`

**배운 내용**
- 중첩 리스트 — 리스트 안에 리스트를 넣으면 `score_table[0][0]` 처럼 **바깥→안쪽 순서로 두 번 인덱싱**한다. 슬라이싱은 값 하나가 아니라 **리스트**를 잘라 준다(`score_table[:-1]`).
- 리스트는 **mutable** — `weekly_sales[3] = 500` 처럼 인덱스로 값을 덮어쓸 수 있다.
- 딕셔너리 — `{key: value}` 형태의 **매핑 자료형**. 리스트가 *번호*로 값을 찾는다면 딕셔너리는 *이름(key)*으로 찾는다. `key` 는 중복 불가, `value` 는 중복 가능.
- 딕셔너리 생성 — `key` 는 문자열·숫자 모두 가능하고, `value` 자리에는 리스트도 들어간다(`{'name': ['김진호', '이지현']}`).
- 값 꺼내기 두 가지 — `d[key]` 는 없는 key 면 **KeyError**, `d.get(key)` 는 에러 없이 **None** 을 반환한다.
- 추가와 수정은 같은 문법 — `d[key] = value` 가 **없는 key 면 추가, 있는 key 면 덮어쓰기**.
- 삭제 — `del d[key]` 는 key 하나, `d.clear()` 는 전체를 비운다.
- 튜플 — `( )` 로 묶고 인덱싱·슬라이싱은 되지만 **값 변경은 불가능(immutable)**. 바꾸려 하면 `TypeError`. 바뀔 수 있는 값은 리스트(장바구니), 바뀌면 안 되는 값은 튜플(생년월일, RGB).
- 숫자형 — 개수는 `int`, 평균·키처럼 소수점이 필요하면 `float`. `type()` 으로 확인한다.
- 연산자 — `/` 는 결과가 항상 실수, `**` 는 제곱, `//` 는 몫, `%` 는 나머지. **2로 나눈 나머지가 0이면 짝수, 1이면 홀수**.
- 여러 줄 문자열 — 따옴표 3개로 감싼다. `len()` 은 **줄바꿈(`\n`)도 한 글자로** 센다.
- 문자열 인덱싱·슬라이싱 — 앞은 `0`부터, 뒤는 `-1`부터. `[시작:끝]` 은 **끝 번호 직전까지**, `[시작:끝:간격]` 으로 건너뛸 수도 있다.
- 문자열 연산 — `+` 는 연결, `*` 는 반복(`"=" * 20` 으로 구분선 만들기).
- 불(bool) — 비교 연산의 결과는 항상 `True`/`False` 이고, `True`는 1·`False`는 0처럼 계산되어 **개수 세기**에 쓸 수 있다.
