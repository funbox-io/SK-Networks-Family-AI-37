# 유클리드 거리 순서대로 정리

## 0. 먼저 알아둘 것: 임베딩 = 점

코사인 유사도에서는 임베딩을 원점에서 뻗은 **화살표**로 봤다.
유클리드 거리에서는 화살표 끝의 **점**만 본다.

유클리드 거리는 **두 점 사이를 자로 잰 직선 거리**다.

| 값 | 의미 |
|---|---|
| 0 | 완전히 같은 점 |
| 작음 | 가까움 → 비슷함 |
| 큼 | 멀리 떨어짐 → 다름 |

코사인 유사도와 반대로 **작을수록 비슷하다.** (점수가 아니라 거리라서)

공식:

```
유클리드 거리 = √( (x 차이)² + (y 차이)² + ... )
```

이걸 3단계로 나눠서 본다.

---

## 1단계: 같은 자리끼리 빼기

```
A = [1, 2]
B = [4, 6]

① x끼리 빼기:  4 - 1 = 3
② y끼리 빼기:  6 - 2 = 4
```

차이는 **[3, 4]**. 가로로 3, 세로로 4만큼 떨어져 있다는 뜻이다.

---

## 2단계: 제곱해서 더하기

```
3² + 4² = 9 + 16 = 25
```

### 제곱하는 이유

빼는 순서에 따라 차이가 음수가 될 수도 있다. (1 - 4 = -3)
음수와 양수를 그냥 더하면 서로 지워져 버린다.
**제곱하면 전부 양수**가 되고, 방향에 상관없이 "떨어진 정도"만 남는다.

```
(-3)² = 9      3² = 9      → 같다
```

---

## 3단계: 루트 씌우기

```
√25 = 5
```

A와 B 사이의 거리는 **5**.

### 루트를 씌우는 이유

2단계에서 제곱을 했으니 단위가 "길이²"가 되어 있다.
루트로 되돌려야 원래 길이 단위로 돌아온다.

이건 **피타고라스 정리**와 같다.
가로 3, 세로 4인 직각삼각형의 빗변 = 5.
(코사인 유사도의 "화살표 길이 구하기"와 계산 방법이 똑같다. 원점 대신 다른 점에서 잰 길이일 뿐이다.)

```
        B (4, 6)
        /|
     5 / | 4
      /  |
     /___|
 A (1, 2)  3
```

---

## 코사인 유사도와 비교

### 예시 1: 방향은 같고 길이만 다를 때

```
A = [3, 4]     B = [6, 8]   ← 같은 방향, 길이만 2배

코사인 유사도:  1      → "완전히 같다"
유클리드 거리:
  차이:  [6-3, 8-4] = [3, 4]
  제곱합: 9 + 16    = 25
  루트:  √25        = 5     → "5만큼 떨어져 있다"
```

같은 두 벡터를 두고 판단이 갈린다.

- **코사인**: 방향만 본다 → 같은 의미
- **유클리드**: 위치를 본다 → 길이가 다르면 멀다

텍스트 임베딩에서는 **"얼마나 강하게"보다 "어떤 의미 쪽인지"** 가 중요해서 보통 코사인을 더 많이 쓴다.

### 예시 2: 길이를 1로 맞추면 둘은 같은 말을 한다

벡터 길이를 모두 1로 맞추면(정규화), 두 지표 사이에 이런 관계가 생긴다.

```
유클리드 거리² = 2 - 2 × 코사인 유사도
```

확인해 보자. 길이가 1인 두 벡터:

```
A = [0.6, 0.8]     B = [0.8, -0.6]

코사인 유사도:  0.6×0.8 + 0.8×(-0.6) = 0.48 - 0.48 = 0   (직각)

유클리드 거리²:
  차이:   [0.2, -1.4]
  제곱합: 0.04 + 1.96 = 2

공식으로:  2 - 2 × 0 = 2   ✅ 같다
```

그래서 OpenAI 임베딩처럼 **이미 길이가 1로 정규화된 벡터**라면,
코사인으로 보든 유클리드로 보든 **가까운 순서는 똑같이** 나온다.
영상의 Embedding Projector에서 두 기준의 결과가 비슷했던 이유다.

| | 코사인 유사도 | 유클리드 거리 |
|---|---|---|
| 보는 것 | 방향(각도) | 위치(직선 거리) |
| 비슷할수록 | 1에 가까움 (큼) | 0에 가까움 (작음) |
| 길이 영향 | 없음 | 있음 |
| 정규화된 벡터에서 | 순위 같음 | 순위 같음 |

---

## 한 줄 요약

> **같은 자리끼리 빼고, 제곱해서 더하고, 루트를 씌우면 두 점 사이의 직선 거리가 나온다.**

---

## 파이썬으로 확인

```python
import numpy as np

def euclid(a, b):
    diff = b - a                      # 1단계: 빼기
    sq_sum = np.sum(diff ** 2)        # 2단계: 제곱해서 더하기
    return np.sqrt(sq_sum)            # 3단계: 루트

print(euclid(np.array([1, 2]), np.array([4, 6])))   # 5.0
print(euclid(np.array([3, 4]), np.array([6, 8])))   # 5.0  (코사인으로는 1.0)

# 한 줄 버전
print(np.linalg.norm(np.array([4, 6]) - np.array([1, 2])))   # 5.0

# 정규화된 벡터에서 관계 확인
a, b = np.array([0.6, 0.8]), np.array([0.8, -0.6])
print(euclid(a, b) ** 2, 2 - 2 * np.dot(a, b))      # 2.0 2.0
```

실제 임베딩은 1536차원이어도 "빼고 → 제곱해서 더하고 → 루트" 순서는 똑같다. 더할 칸이 1536개로 늘어날 뿐이다.
