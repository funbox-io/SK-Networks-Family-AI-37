# PCA(주성분 분석) 차원 축소 순서대로 정리

## 0. 먼저 알아둘 것: 그림자로 줄이기

임베딩은 1536차원이라 눈으로 볼 수 없다.
PCA는 고차원 점들을 2차원·3차원으로 줄여서 **그림으로 볼 수 있게** 해 준다.

핵심 아이디어는 **그림자**다.

> 물체에 빛을 비추면 3D가 2D 그림자가 된다.
> 빛을 어느 방향에서 비추느냐에 따라 그림자가 잘 퍼지기도 하고, 한 점으로 뭉개지기도 한다.
> PCA는 **그림자가 가장 넓게 퍼지는 방향**을 찾아서 그쪽으로 그림자를 떨어뜨린다.

점들이 넓게 퍼져 있어야 서로 구분이 된다. 뭉개지면 정보가 사라진다.

이걸 3단계로 나눠서 본다. 쉽게 보기 위해 **2차원 → 1차원**으로 줄이는 예시를 쓴다.

### 예시 점 4개

```
점1 = [1, 2]
점2 = [2, 1]
점3 = [3, 4]
점4 = [4, 3]
```

---

## 1단계: 가운데로 옮기기 (평균 빼기)

**각 축의 평균을 구해서, 모든 점에서 뺀다.**

```
x 평균: (1 + 2 + 3 + 4) ÷ 4 = 2.5
y 평균: (2 + 1 + 4 + 3) ÷ 4 = 2.5

점1: [1 - 2.5, 2 - 2.5] = [-1.5, -0.5]
점2: [2 - 2.5, 1 - 2.5] = [-0.5, -1.5]
점3: [3 - 2.5, 4 - 2.5] = [ 0.5,  1.5]
점4: [4 - 2.5, 3 - 2.5] = [ 1.5,  0.5]
```

### 가운데로 옮기는 이유

PCA는 "원점에서 어느 방향으로 퍼져 있나"를 본다.
점 무리가 원점에서 멀리 떨어져 있으면, 퍼짐 대신 **"원점에서 얼마나 멀리 있나"** 가 섞여 버린다.
무리의 중심을 원점에 맞춰야 순수하게 퍼진 모양만 남는다.

---

## 2단계: 그림자가 가장 넓게 퍼지는 방향 찾기

### 2-1. 그림자 길이 = 내적

점을 어떤 방향(길이 1인 화살표)에 비췄을 때 생기는 그림자의 위치는 **내적**으로 구한다.
(코사인 유사도 1단계의 그 내적이다.)

```
점 [-1.5, -0.5]를 x축 방향 [1, 0]에 비추면
그림자 = (-1.5)×1 + (-0.5)×0 = -1.5
```

### 2-2. 방향 몇 개 시험해 보기

그림자들이 얼마나 퍼졌는지는 **분산**(평균에서 떨어진 거리의 제곱 평균)으로 잰다.
(여기서는 데이터 개수 - 1 = 3으로 나눈다.)

**방향 ①: x축 → [1, 0]**

```
그림자:  -1.5, -0.5, 0.5, 1.5
분산:    (2.25 + 0.25 + 0.25 + 2.25) ÷ 3 = 1.67
```

**방향 ②: 대각선 ↗ → [0.707, 0.707]**  (길이 1로 맞춘 [1, 1])

```
점1: -1.5×0.707 + (-0.5)×0.707 = -1.414
점2: -0.5×0.707 + (-1.5)×0.707 = -1.414
점3:  0.5×0.707 +   1.5 ×0.707 =  1.414
점4:  1.5×0.707 +   0.5 ×0.707 =  1.414

분산: (2 + 2 + 2 + 2) ÷ 3 = 2.67    ← 가장 큼!
```

**방향 ③: 대각선 ↘ → [0.707, -0.707]**

```
그림자:  -0.707, 0.707, -0.707, 0.707
분산:    (0.5 + 0.5 + 0.5 + 0.5) ÷ 3 = 0.67
```

| 방향 | 그림자 분산 |
|---|---|
| ① x축 | 1.67 |
| ② ↗ 대각선 | **2.67** ← 1등 |
| ③ ↘ 대각선 | 0.67 |

**↗ 대각선**으로 비출 때 그림자가 가장 넓게 퍼진다. 이 방향이 **제1주성분(PC1)** 이다.

### 실제 PCA는 이렇게 하나하나 시험하지 않는다

모든 방향을 다 시험할 수는 없으니, 실제로는 **공분산 행렬의 고유벡터**라는 계산으로 "분산이 가장 큰 방향"을 한 번에 구한다.
지금은 **"그림자가 가장 퍼지는 방향을 찾는 계산"** 이라고만 이해해도 충분하다.

- 1등 방향 → 제1주성분 (PC1)
- 1등과 직각인 방향 중 1등 → 제2주성분 (PC2)
- 그다음 → 제3주성분 (PC3) ...

Embedding Projector의 3D 화면은 PC1, PC2, PC3을 X, Y, Z축으로 쓴 것이다.

---

## 3단계: 그 방향으로 그림자 떨어뜨리기 (투영)

PC1 방향으로 비춘 그림자가 곧 **새 좌표**다.

```
점1 [1, 2]  →  -1.414
점2 [2, 1]  →  -1.414
점3 [3, 4]  →   1.414
점4 [4, 3]  →   1.414
```

숫자 2개였던 점이 **숫자 1개**로 줄었다. 2차원 → 1차원 축소 완료.

```
     점1·점2                  점3·점4
  ──────●──────────┼──────────●──────▶ PC1
      -1.414       0        1.414
```

### 얼마나 정보를 살렸나 (설명된 분산 비율)

```
전체 분산 = 방향 ② 분산 + 방향 ③ 분산 = 2.67 + 0.67 = 3.33
PC1이 가진 비율 = 2.67 ÷ 3.33 = 0.8   → 80%
```

1차원으로 줄였는데도 원래 퍼짐 정보의 **80%** 를 살렸다는 뜻이다.
나머지 20%(↘ 방향의 차이, 점1과 점2가 다르다는 정보)는 버려졌다.
그래서 위 그림에서 점1과 점2가 한 점에 겹쳐 보인다.

### 영상에서 "어느 각도로 압축하냐에 따라 그림이 달라진다"고 한 이유

1536차원을 2~3차원으로 줄이면 **버려지는 정보가 아주 많다.**
그림에서 가까워 보여도 실제로는 멀 수 있고, 그 반대도 가능하다.
그래서 정확한 비교는 **원래 차원에서 코사인 유사도로** 하고, PCA 그림은 **대략적인 모양을 보는 용도**로 쓴다.

---

## 한 줄 요약

> **가운데로 옮기고, 그림자가 가장 넓게 퍼지는 방향을 찾아서, 그 방향으로 그림자를 떨어뜨리면 차원이 줄어든다.**

---

## 파이썬으로 확인

```python
import numpy as np

X = np.array([[1, 2], [2, 1], [3, 4], [4, 3]], dtype=float)

# 1단계: 가운데로 옮기기
Xc = X - X.mean(axis=0)

# 2단계: 방향 몇 개 시험 → 그림자 분산 비교
for d in [[1, 0], [1, 1], [1, -1]]:
    d = np.array(d) / np.linalg.norm(d)          # 길이 1로 맞추기
    shadow = Xc @ d                              # 내적 = 그림자
    print(d.round(3), shadow.var(ddof=1).round(2))
# [1. 0.]          1.67
# [0.707 0.707]    2.67   ← 가장 큼
# [0.707 -0.707]   0.67

# 3단계: PC1 방향으로 투영
pc1 = np.array([1, 1]) / np.sqrt(2)
print((Xc @ pc1).round(3))                      # [-1.414 -1.414  1.414  1.414]
```

### scikit-learn으로 한 번에

```python
from sklearn.decomposition import PCA

pca = PCA(n_components=1)
print(pca.fit_transform(X).ravel().round(3))     # [-1.414 -1.414  1.414  1.414]
print(pca.components_)                           # [[0.707 0.707]]  ← PC1 방향
print(pca.explained_variance_ratio_)             # [0.8]            ← 80%
```

임베딩 1536차원을 3차원으로 줄일 때도 `PCA(n_components=3)`으로 바꾸기만 하면 되고, 원리는 위 3단계와 똑같다.
