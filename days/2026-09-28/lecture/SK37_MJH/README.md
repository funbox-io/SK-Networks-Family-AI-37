# 대한민국 명절 교통사고 데이터 — 버전 B6 (MySQL 연동 · 접속 정보 db_config.py)

> 설날 vs 추석, 어떤 연휴가 더 위험할까?

「명절의 밤」 디자인을 흰 바탕으로 옮긴 라이트 테마 (설날 = 하늘색, 추석 = 호박색 · 글자는 흰 바탕에서 잘 읽히는 진한 색). 제목 Noto Serif KR · 본문 Pretendard · 숫자 Space Grotesk.

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py      # 반드시 이 폴더 안에서 실행 (.streamlit/config.toml 테마 적용)
```
Streamlit 1.44 이상이 필요합니다. 웹 글꼴(Pretendard 등)은 인터넷 연결 시 불러오고, 없으면 시스템 한글 글꼴로 표시됩니다.

### MySQL에서 읽기
1. `db/README.md` 순서대로 MySQL Workbench에서 `db/holiday_db.sql`을 실행해 `holiday_db`를 만듭니다.
2. 이 폴더의 `db_config.py`를 메모장 등으로 열어 `password`를 내 MySQL root 비밀번호로 바꿉니다 (그대로 적는 평문).
   (비밀번호가 보이는 파일이니 GitHub 등에 올릴 때는 지우고 올리세요.)
3. `streamlit run app.py` — 사이드바 아래에 **데이터: MySQL holiday_db**가 보이면 DB에서 읽은 것입니다.

접속 정보가 없거나 연결에 실패하면 앱이 멈추지 않고 data/ 폴더의 CSV로 대신 표시하며, 사이드바에 노란 경고로 이유를 알려 줍니다.
DB 내용은 10분 동안 캐시됩니다(데이터를 바꿨다면 오른쪽 위 메뉴 → Clear cache).

## 파일

| app.py | 페이지 뼈대 (사이트 제목 · 사이드바 메뉴/지표/일평균 보정 · 세 탭) |
| db_config.py | MySQL 접속 정보 (host · port · user · password · database) — 비밀번호는 여기만 바꾸면 됨 |
| data_source.py | 데이터 불러오기 — MySQL(holiday_db) 우선, 실패 시 CSV |

| theme.py | 색 · 글꼴 · CSS · 머리글 — **디자인은 이 파일만 바꾸면 됩니다** |
| analysis.py | 계산 (명절 당일 D 기준 일자, 히트맵, 피해 구성, 사고다발지 연도 연결 등) |
| faq.py | 보험 FAQ 화면 (data/faq/insurance_faq.csv 348개 · 답변 끝 '(출처 : …)'는 출처 표시로 분리) |

| data/ | 연휴 사고통계 2021~2025, 사고다발지 81곳, 시도 경계, 보험 FAQ CSV(insurance_faq.csv) |

## 데이터 메모
- D = 음력 1월 1일 · 8월 15일 당일. 연휴 길이가 3~5일로 달라 일평균 보정을 켜고 비교하세요.
- 부상자에는 중상자가 포함됩니다. 치사율 = 사망 ÷ 사고 × 100.
- 사고다발지는 2021~2025 합산(연도·명절 구분 없음). 연도를 고르면 툴팁·목록에 소속 시군구의 그해 연휴 수치가 함께 나옵니다.

출처: 도로교통공단, 설날·추석 연휴기간 사고통계(2021~2025), 연휴기간 사고다발지역(2021~2025). 인용 표기는 팀 DataFact 가이드 형식에 맞춰 수정하세요.
